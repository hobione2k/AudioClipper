# 仕様

## 動作環境

ブラウザ上でローカル動作

## 機能

### オーディオファイルのクリッピング

* オーディオファイルの読み込み
* 任意の範囲を指定して削除
* 編集後のオーディオファイルのエクスポート

#### 対応ファイル

* 読み込み：wav / mp3 / ogg / flac / m4a（ブラウザ標準のデコード機能を使用）
* 書き出し：wav / ogg (Opus) / m4a (AAC)（ogg・m4a は Chrome 標準の WebCodecs で圧縮し、入れ物は自前で組み立てる）

### GUI

* オーディオ波形が表示される
* ドラッグで切り取る範囲を指定します。
* 波形の表示範囲を拡大・縮小・スクロールできる
  * 拡大・縮小：ボタン（縮小／拡大／全体表示／選択範囲を拡大）、+ / - / 0 キー、Ctrl（⌘）+ホイール（マウス位置を中心）、スマホは2本指ピンチ
  * スクロール：波形下のスクロールバー、Shift+ホイール、トラックパッドの横スクロール
  * 範囲選択のドラッグ中に波形の端を越えると、その方向へ自動でスクロールする
  * 再生中に再生位置が表示範囲の外に出ると、次の範囲へ自動でページ送りする
* 再生音量をスライダーで調整できる（0〜200%、ダブルクリックで100%に戻す。再生時のみ反映され、エクスポートには影響しない）
* ダークテーマ／ライトテーマをヘッダー右上のボタンで切り替えられる（初回はOSの設定に従い、切り替えた設定はブラウザに保存される）
