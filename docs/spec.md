# 仕様

## 動作環境

ブラウザ上でローカル動作

## 機能

### オーディオファイルのクリッピング

* オーディオファイルの読み込み
* 任意の範囲を指定して削除
* 編集後のオーディオファイルのエクスポート

#### 対応ファイル

* 読み込み：wav / mp3 / ogg / flac / m4a（ブラウザ標準のデコード機能を使用）
* 書き出し：wav / ogg (Opus) / m4a (AAC)（ogg・m4a は Chrome 標準の WebCodecs で圧縮し、入れ物は自前で組み立てる）

### GUI

* オーディオ波形が表示される
* ドラッグで切り取る範囲を指定します。
* 再生音量をスライダーで調整できる（0〜200%、ダブルクリックで100%に戻す。再生時のみ反映され、エクスポートには影響しない）
* ダークテーマ／ライトテーマをヘッダー右上のボタンで切り替えられる（初回はOSの設定に従い、切り替えた設定はブラウザに保存される）
