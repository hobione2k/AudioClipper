# AudioClipper

ローカルブラウザ上で動くオーディオ編集ツール

## 使い方

1. [こちらのページ](https://hobione2k.github.io/AudioClipper/)、または`index.html` をブラウザ（Chrome / Edge / Firefox など）で開く
2. オーディオファイル（WAV / MP3 / OGG / FLAC / M4A）をドロップ、またはクリックして選択
3. 波形をドラッグして削除したい範囲を選択
4. 「選択範囲を削除」（または Delete キー）で削除
5. 形式（WAV / OGG / M4A）を選んで「エクスポート」で編集後のファイルを保存

WAV 以外のファイルはブラウザ既定のサンプルレート（多くは 48kHz）に変換されて読み込まれます。

### 書き出し形式

| 形式 | 内容 |
| --- | --- |
| WAV | 16bit / 24bit PCM、32bit float（元のサンプルレートのまま） |
| OGG (Opus) | 48kHz・2ch まで。ビットレート 96〜192kbps |
| M4A (AAC) | 44.1kHz / 48kHz・2ch まで。ビットレート 96〜192kbps |

OGG・M4A は Chrome 標準の WebCodecs を使って書き出します（ライブラリ不要）。ブラウザが対応していない形式は選択肢に「非対応」と表示されます。

サーバーやインストールは不要で、音声データが外部に送信されることはありません。

## 操作一覧

| 操作 | 内容 |
| --- | --- |
| ドラッグ | 範囲を選択 |
| クリック | 再生開始位置を指定 |
| Shift+クリック | 選択範囲を拡張 |
| Space | 再生 / 停止（選択中は選択範囲のみ再生） |
| Delete / Backspace | 選択範囲を削除 |
| Ctrl+Z | 元に戻す |
| Esc | 選択を解除 |

## ファイル構成

* `index.html` … 画面
* `css/style.css` … デザイン
* `js/app.js` … 読み込み・波形描画・範囲選択・削除・再生・書き出し操作
* `js/encoders.js` … WAV / OGG / M4A のエンコード処理
